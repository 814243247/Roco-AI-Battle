# 🛡️ 洛克王国：世界 · 巅峰赛核心对战情报 (Top-Level Intelligence)

> [!IMPORTANT]
> **2026 核心版本平衡性更新**：
> 1. **草系克制强化**：草系现在对光系造成 2 倍伤害（此前为 0.5 倍）。这使得草系精灵（如兽花蕾）成为了反制光系核心（如独角兽）的关键。
> 2. **冰系抗性调整**：冰系现在抵抗光系攻击。
> 3. **属性三角**：光 -> (恶, 幽, 龙)；恶 -> (幽, 萌)；幽 -> (幽, 萌)。

## 🔝 第一部分：当前 Meta T0 精灵手册

### 1. 罗隐 (Luo Yin) —— 「资源中转与高防屏障」
- **定位**：利用极高物防首发，通过“护盾/回复”积攒能量储备。
- **克制**：怕水、草系魔攻手。遇到“朔夜伊芙”这种强制换位或削能精灵需谨慎。

### 2. 圆号鱼 (French Horn Fish) —— 「印记流核心 / T0 首发」
- **定位**：S1 赛季最强首发之一。
- **核心逻辑**：极速叠加 3 层印记，为全队提供回复或为后期爆发位铺路。
- **博弈点**：如果对手首发是“火神”，需通过操作规避先手冲击。

### 3. 暗兔 (Dark Rabbit) —— 「毒系克星 / 叠层收割」
- **定位**：针对性反击。
- **核心逻辑**：只要对手有层数，暗兔能够实现 1-2 回合快速清场。
- **操作逻辑**：在对手毒系/印记体系成型中盘切入，瞬间扭转局势。

### 4. 狐狸 (Fox) —— 「清道夫 / 龙系天敌」
- **定位**：驱散控制位。
- **核心逻辑**：专门针对“龙系”这种依赖大量 Buff 堆砌的阵容，强制驱散对手状态。

## 🧠 第二部分：2026 S1 赛季主流战术 (Advanced Meta)

### 1. 独角兽均衡流 (Unicorn Equilibrium)
- **阵容**：圆号鱼 + 辅助工具人 + 白金独角兽。
- **打法**：通过高防宠（圆号鱼）的“纠缠/响应”技能消耗对手资源，保护独角兽无损上场，最后大招收割。

### 2. 海枝枝伏击流 (Strategic Ambush)
- **阵容**：朔夜伊芙 + 海枝枝。
- **打法**：朔夜伊芙使用“等价交换”或高压控制逼迫对方换人，触发海枝枝被动实现能量压制。

### 3. 雷雨/武斗速攻流 (Martial Burst)
- **阵容**：猫教练 + 小八 + 强力爆发位。
- **打法**：极致卷速度。利用猫教练的物攻 Buff 和小八的抗性/速度 Buff，达成“出手即必杀”。

## 🎭 第三部分：高阶意识流博弈 (Mental Warfare)

### 1. 先制权博弈 (Priority War)
- **核心准则**：巅峰赛不仅是数值对比，更是“先制级”的博弈。必须熟记核心技能的先制值（+1, +2, +3）。
- **心理操作**：故意留在场上诱导对方使用低先制大招，在最后一刻切换具有“先手控制”的精灵。

### 2. 诱导切换 (The Bait & Switch)
- **原理**：利用属性劣势宠作为诱饵，诱导对手释放特定克制技能。
- **反制**：瞬间切换至“拦截宠”（如尘铁兽/狐狸），在入场瞬间清除对手的强化 Buff，变被动为主动。

### 3. 5能量心理博弈 (Forbidden Energy)
- 当双龙或王位精灵满能量时，对手往往会进行“联防”。此时 AI 应考虑使用 0 能耗的“虚招”或回复技能，诱导对方浪费换人次数，从而拉开资源差。
